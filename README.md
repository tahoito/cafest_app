# ☕️ Cafest

**名古屋カフェ特化型 SNS Webアプリ**

ユーザーはカフェを探し、写真やレビューを投稿できます。  
店舗側は公式情報（営業時間・予算・メニュー・雰囲気など）を掲載でき、  
「リアルな雰囲気」と「正確な店舗情報」を一つのアプリで確認できます。

## 🌟 コンセプト

名古屋のカフェに特化し、
「雰囲気で探せるSNS体験」と「正確な店舗公式情報」を
一つのアプリで完結させる。

SNSのように写真やレビューから直感的に探せる
営業時間・予算・場所などの公式情報も同時に確認できる
名古屋エリアに特化することで、地元目線の情報が集まる
「見るだけで終わらない、行くまで完結するカフェSNS」を目指す。

## 🎯 ターゲット

- 10代後半〜20代
- TikTok / Instagram をよく利用する人
- 友達と出かけることが多い人
- 写真を撮る・共有するのが好きな人
- 名古屋のカフェ巡りが好きな人

---

## ❓ 解決したい課題

- SNSと店舗情報が分かれており、一つのアプリで完結しない
- 公式情報とユーザー投稿が分離していて使いづらい
- 名古屋のカフェに特化したSNSがなく、地元情報が探しにくい
- 雰囲気や感性を重視してカフェを探しづらい

---

## ✨ 提供する価値

- 写真・レビュー・公式情報を1画面で確認可能
- SNSと検索アプリを行き来する手間を削減
- 雰囲気・価格帯・エリアから直感的にカフェを探せる
-「どこ行く？」をすぐ決められる体験を提供

## 🧭 主な機能

### ユーザー向け
- おすすめカフェ表示
- 絞り込み検索  
  （予算 / エリア / 営業時間 / レビュー / タグ）
- カフェ詳細ページ / メニューページ
- 写真・レビュー投稿
- お気に入り保存
- 閲覧履歴
- 予約機能

### 店舗向け
- 店舗公式ページ
- 店舗情報管理（営業時間・予算・説明文）
- メニュー表管理
- 閲覧数一覧
- レビュー一覧
- 予約状況管理

---

## ⭐️ 特徴・強み

- 店舗公式情報 × ユーザー投稿の共存
- 店舗公式プロフィールを掲載可能
- 営業時間・予算・説明文・雰囲気タグを登録
- メニュー写真・内観写真を掲載
- 写真付きレビューを投稿
- 雰囲気・価格帯・エリアで検索
- 実際の来店写真をギャラリー形式で閲覧
- 気に入ったカフェをお気に入り保存
  
「公式情報の信頼性」と「ユーザー投稿のリアルさ」
この2つが一つのアプリに集まる点が最大の強み。


### 店舗公式情報 × ユーザー投稿の共存

**店舗側**
- 店舗公式プロフィールを掲載
- 営業時間・予算・説明文・雰囲気タグを登録
- メニュー写真・内観写真を掲載

**ユーザー側**
- 写真付きレビューを投稿
- 雰囲気・価格帯・エリアで検索
- カフェのリアルな写真をギャラリー形式で閲覧
- 気に入ったカフェをお気に入り保存

👉 店舗公式情報とユーザーのリアルな投稿が  
一つのアプリ内で共存することが最大の特徴です。
